# 1. Оптимізація виробництва напоїв

Це завдання розв'язане за допомогою лінійного програмування та бібліотеки `PuLP`.

## Опис задачі
Метою було максимізувати загальну кількість вироблених напоїв ("Лимонад" та "Фруктовий сік") за умови обмежених ресурсів: води, цукру, лимонного соку та фруктового пюре.

## Результати
На основі моделі було визначено оптимальний план виробництва:
- **Лимонад:** 30 одиниць
- **Фруктовий сік:** 20 одиниць
- **Загальна кількість:** 50 одиниць

Всі обмеження щодо ресурсів були дотримані, а використання води було оптимізовано для досягнення максимального випуску.

# 2. Аналіз обчислення інтеграла методом Монте-Карло

## Опис завдання
Було проведено обчислення визначеного інтеграла для функції $f(x) = x^2$ на інтервалі $[0, 2]$. Метою було порівняти точність методу Монте-Карло з аналітичним розв'язком (використовуючи функцію `quad` бібліотеки SciPy).

## Результати обчислень
- **Метод Монте-Карло (15,000 точок):** ~2.6584 (результат може дещо змінюватися при кожному запуску)
- **Результат функції `quad`:** 2.666666666666667
- **Аналітичне значення:** $\int_{0}^{2} x^2 dx = [\frac{x^3}{3}]_0^2 = \frac{8}{3} \approx 2.6667$

## Висновки
1. **Точність:** Метод Монте-Карло дає результат, дуже близький до істинного значення інтеграла. Похибка зазвичай становить менше 1% при достатній кількості випадкових точок (10,000+).
2. **Залежність від кількості точок:** Точність методу напряму залежить від кількості ітерацій. При збільшенні кількості випадкових точок результат стабільно наближається до значення, отриманого функцією `quad`.
3. **Практичне застосування:** Хоча функція `quad` працює швидше і точніше для простих функцій, метод Монте-Карло є незамінним для обчислення багатовимірних інтегралів або площ областей зі складними межами, де аналітичне рішення є неможливим.
